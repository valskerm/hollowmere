# Hollowmere battle maps

One background image per map, 104 in all. Put each in a maps folder next to index.html, named exactly as in the File column (JPEG). The image is stretched over the grid, so match the aspect ratio of the size given. Squares are 5 ft; about 70 px per square looks sharp on phones (a 10-square-wide map would be 700 px wide). Missing images fall back to the plain grid.

Patrols, bounties and raids use the standard 10 by 12 board with no background.

## Shapes

- **tunnel**: long and narrow, with broken walls along both sides.
- **hall**: rows of pillars.
- **cave**: irregular rock clusters.
- **forest**: scattered trees.
- **ruins** and **street**: blocks of walls or buildings.
- **open**: a few boulders.

The game places obstacles randomly for each shape, so the art sets the scene and does not need to match the exact obstacle squares.
